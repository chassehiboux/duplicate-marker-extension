# Поиск ФССП по нескольким департаментам и базам

## Спецификация

В окне поиска доступны множественные значения типа, статуса, пользователя,
ИНН и имени взыскателя. Значения одного фильтра объединяются через ИЛИ,
разные фильтры — через И. Пустой выбор означает отсутствие ограничения.
Даты остаются диапазоном, идентификатор и имя файла — текстовыми условиями.

В общем блоке фильтров находится список всех доступных департаментов со всех
баз, включая скрытые в меню страницы. Изначально выбран текущий департамент.
Текущий выбранный департамент обрабатывается первым, остальные — в порядке меню.
Переход выполняется в той же вкладке через свежую штатную ссылку переключения.
После загрузки проверяется активный depid и база, автоматически открывается
окно с прежними фильтрами, условиями, результатами и продолжением поиска.

Реестр считается уже проверенным только после успешного чтения, по ключу
«база + Id + FileName + LastProcessing». Изменение любого компонента вызывает
повторную проверку. Между независимыми базами одинаковые номера не объединяются.
Результат содержит базу и департамент, ссылки ведут к исходной базе и depid.
Ссылка сначала открывает список в базе, где сформирован результат, затем
использует свежую штатную ссылку для входа в исходную базу и департамент записи.
Это сохраняет переход между базами, когда предыдущая база уже требует нового входа.
По завершении вкладка остаётся на последнем выбранном департаменте.
При ошибке, отсутствии доступа или неподтверждённом переключении поиск
останавливается с сохранёнными результатами, не пропуская департамент молча.

Состояние переходов хранится только в chrome.storage.session, отдельно на вкладку,
с ограничением времени жизни. На закрытие окна поиска или вкладки удаляется.
Это временная задача, не пользовательские настройки: storage.local и Supabase
не используются. Токены ссылок переключения в состояние не записываются.
Checkpoint создаётся перед переходом; ручная перезагрузка повторяет только
работу после последнего checkpoint. Совпадения дедуплицируются по базе и записи.

## План / задачи

1. Реализовать мультивыбор, список департаментов и фильтры с группами ИЛИ.
2. Добавить временный фоновый обмен состоянием, независимый для каждой вкладки.
3. Реализовать сериализацию результатов, переходы, восстановление и пропуск реестров.
4. Обновить происхождение результатов и ссылки, добавить проверки сценариев.
5. Проверить сборку Firefox и Chrome, чистоту файлов, выполнить отдельный коммит.

## Scope gate

StageTimer — нет. Content script, background и состав сборки Firefox — да.
Manifest и permissions — без изменений, используются уже разрешённые API.
Новый фоновый модуль копируется deploy.py и явно включается deploy-firefox.py.
deploy_VZID.py не содержит поиск ФССП, его поведение не меняется.
Новые элементы вложены в существующее окно, F2 и скрытие при скриншоте наследуются.
Постоянные ключи, Supabase, Apps Script и Google Sheets — нет.

## Быстрый старт

Выбрать департаменты и значения общих фильтров, заполнить нужные таблицы условий
и нажать «Поиск». Вкладка будет последовательно переключаться; закрытие окна
отменяет всю задачу. «Стоп» приостанавливает текущий поиск, «Продолжить» возобновляет.
Excel содержит общий накопленный результат со сведениями о базе и департаменте.

## Выполненные проверки

14 автоматических проверок: фильтры И/ИЛИ, даты, состав столбцов, сопоставление,
изменение ключей реестров, пропуск только успешно прочитанных, сериализация,
изоляция вкладок, истечение сессии, закрытие вкладки, ошибки хранилища, Excel
и ссылки на исходный depid без сохранённых токенов авторизации.

В установленном расширении Chrome выполнен поиск с двумя статусами по depid
39 → 43 → 6. Поиск сам прошёл через Курган, Курган-Восточный и Ноябрьск,
сменил базу с kgn.pyramid.vostok-electra.ru на pyramid.vostok-electra.ru,
восстановил окно и сохранил найденную запись из depid 39. Отдельно проверено
возвращение из основной базы к найденной записи 22440 в Кургане, depid 39.

Firefox-сборка проверена в системном временном каталоге: новый модуль скопирован
и включён в background.scripts, синтаксис фоновых файлов корректен, тесты
в сборку не попадают. Публикация и внешние деплои не выполнялись.
