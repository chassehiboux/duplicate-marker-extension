# План: проверка списания по реестрам ДЗ

1. Превратить кнопку проверки исходящих в кнопку-меню «Проверка» с двумя согласованными действиями.
2. Добавить отдельную модель дневной сессии новой проверки по `depid`, восстановление и исключение
   уже обработанных строк текущего дня.
3. Повторно использовать период по «Дате запуска поручения на списание» и сбор всех страниц грида,
   оставляя строки с исходящим и незаполненной датой либо номером приказа.
4. Расширить фоновую работу с WSS: извлечь исходящий, количество, сумму, ответственного, решение,
   входящие и другие документы.
5. Добавить переносимый между страницами компактный оверлей ручной сверки, навигацию по документам,
   маску даты, свободный номер приказа и клавиатурный поток `Tab`/`Enter`.
6. Подсвечивать исходящий и нормализованную целую часть суммы на HTML-страницах WSS.
7. После подтверждения пользователя возвращаться к строке, штатно сохранять решение в комментарии,
   затем штатно сохранять дату и номер приказа с проверкой значений в гриде.
8. Для отказа сохранять только комментарий; неоднозначные данные останавливать для ручной проверки.
9. Добавить новые элементы в скрытие при скриншоте и существующую настройку F2.
10. Выполнить точечные синтаксические, deploy- и UTF-8-проверки, затем создать отдельный коммит.
