# Поиск ИД в реестрах передачи в ОВЗИД

## Назначение

На странице `/pu/ReestrSendToOVZID` пользователь может найти должника или исполнительный документ внутри всех реестров, которые входят в текущий отфильтрованный список.

## Пользовательский сценарий

1. Пользователь задаёт штатные фильтры списка реестров при необходимости.
2. Нажимает кнопку «Найти ИД в реестрах» в нижней панели таблицы.
3. Заполняет одну или несколько строк поиска. Доступные поля: ЛС, номер ИД, номер дела, ФИО, дата рождения.
4. В одной строке должны совпасть все заполненные поля; разные строки ищутся независимо.
5. Расширение показывает ход проверки, позволяет приостановить и продолжить её.
6. Результат содержит найденные значения и номер реестра.
7. Нажатие на номер открывает реестр в новой вкладке, прокручивает таблицу к найденной записи и подсвечивает её.

## Ограничения и безопасность

- Поиск учитывает текущие фильтры основной таблицы и не переключает департамент.
- Запросы выполняются только к текущему origin Пирамиды с действующей пользовательской сессией.
- Страницы списка обрабатываются последовательно: после загрузки одной страницы сразу проверяются найденные на ней реестры, и только затем загружается следующая.
- Одновременно выполняется не более четырёх запросов состава реестров текущей страницы.
- Поиск можно приостановить; закрытие окна отменяет текущий запуск.
- Новые постоянные пользовательские данные не создаются. Видимость управляется существующей настройкой поиска ИД в реестрах.

## Совместимость

- Функция входит в основное расширение Chrome/Edge и Firefox-сборку.
- Обособленный StageTimer не затрагивается.
- Кнопка и окно скрываются общей настройкой `fsspRegistrySearch` и при скрытии интерфейса расширения для скриншота.
