# Управление чатами ChatGPT

## Пользовательский результат

- При наведении на обычный чат в боковой панели справа появляются две компактные кнопки без текста: архивировать и удалить.
- Кнопки расширения занимают отдельное место перед штатными кнопками ChatGPT и не перекрывают «Закрепить» или меню «…».
- Пока указатель не наведён на чат, быстрые кнопки занимают нулевую ширину и не сокращают название; место для них раскрывается только при наведении.
- Первое нажатие на корзину заменяет её зелёной галочкой. Удаление выполняется только по галочке, а уход указателя со строки отменяет подтверждение.
- После зелёной галочки расширение само нажимает штатную кнопку «Удалить» в диалоге «Удалить чат?»; массовое удаление делает это последовательно для каждого выбранного чата.
- Рядом с кнопкой закрытия боковой панели появляется кнопка массового управления.
- Кнопка открывает окно со всеми обычными чатами аккаунта, поиском, выбором галочками и командами массового архивирования или удаления.
- Окно показывает ход операции и результат по каждому набору выбранных чатов. Оно показывает чаты, уже загруженные в боковой панели; список расширяется по мере загрузки ChatGPT новых строк.
- Внешний вид, размеры, цвета, состояния наведения и тёмная тема следуют текущему интерфейсу ChatGPT.

## Ограничения

- Архивирование и удаление запускаются через штатное меню ChatGPT, поэтому сайт сам выполняет авторизацию запроса; при изменении интерфейса селекторы могут потребовать обновления.
- Быстрые кнопки работают и с обычными, и с показанными в боковой панели проектными чатами; массовый список получает доступные чаты из списка аккаунта ChatGPT.
- Расширение не сохраняет список чатов, содержимое чатов или токены авторизации.

## Безопасность

- Одиночное удаление подтверждается зелёной галочкой прямо в строке; массовое — повторным нажатием на кнопку подтверждения внутри окна.
- Во время массовой операции элементы управления блокируются от повторного запуска.
- Ошибка одного чата не прерывает обработку остальных.
