# План реализации поиска в реестрах передачи в ОВЗИД

1. Добавить отдельный content-модуль для списка и карточки реестра.
2. Добавить кнопку и диалог поиска с согласованными полями.
3. Получать текущее состояние jqGrid через фоновый скрипт.
4. Последовательно загружать страницы отфильтрованного списка; после каждой страницы сразу проверять её реестры с ограниченным параллелизмом.
5. Добавить результаты со ссылкой на точную запись и подсветку строки после перехода.
6. Подключить модуль к основному manifest и Firefox-сборке.
7. Объединить видимость с существующей настройкой поиска ИД в реестрах.
8. Выполнить синтаксические и живые проверки в Edge.
