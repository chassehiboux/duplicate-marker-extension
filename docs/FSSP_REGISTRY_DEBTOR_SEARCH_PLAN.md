# План: поиск должников в реестрах ФССП

## Результаты по каждой строке поиска

1. Создавать свёрнутые блоки для всех непустых строк сразу при запуске поиска.
2. Сохранять порядок ввода, показывать условия и число совпадений в заголовке.
3. Выводить существующие строки результатов внутри соответствующих блоков и
   сохранять раскрытие при обновлениях, паузе и завершении поиска.
4. Проверить нулевые результаты, одинаковые условия, порядок при поступлении
   совпадений в обратном порядке, ссылки и подсказки типа реестра.
5. Сортировать строки внутри каждого блока по числовому ID реестра по убыванию,
   показывать ID и тип реестра в самой ссылке открытия.

Scope этой доработки: content script и вложенный UI поиска ФССП — да; отдельные
элементы меню F2 не нужны, все блоки остаются внутри существующего скрываемого окна.
StageTimer, постоянные ключи, Supabase и мосты — нет. Chrome/Firefox используют один
модуль, состав сборок не меняется; используются стандартные HTML details/summary.

## Вставка столбца из Excel

1. Обрабатывать вставку многострочного текста в существующих полях формы.
2. Заполнять выбранный столбец от текущей строки, сохраняя остальные столбцы.
3. Пропускать пустые строки, добавлять недостающие строки и оставлять пустую в конце.
4. Проверить пример из шести ФИО, вставку в другие столбцы, существующие строки,
   обычную вставку и запрет изменения после запуска поиска.

Scope: изменяется content script поиска ФССП; сборки Chrome и Firefox используют
тот же файл. StageTimer, новые элементы UI/F2, постоянные ключи, Supabase и мосты
Google Sheets/Apps Script не затронуты. Изменения состава сборок не требуются.

Дополнение: передавать `TypeName` из списка реестров в найденные совпадения и
показывать тип в стандартной всплывающей подсказке ссылки с ID; проверить также
реестр без указанного типа. Новых элементов UI и постоянных данных не требуется.

1. Добавить отдельный модуль интерфейса и прямого поиска для страниц `fsspreestr`.
2. Встроить кнопку после «Единый реестр ФССП» и реализовать пакетную форму с автодобавлением строк.
3. Считать параметры текущего jqGrid и получить все отфильтрованные реестры через `/data`.
4. Получать записи реестров через `/{ID}/typedata`, сопоставлять четыре поля локально и поддержать `null`.
5. Добавить отмену по закрытию окна, прогресс и таблицу результатов со ссылками.
6. Реализовать переход к найденной строке: размер страницы, нужная страница, прокрутка и тройная подсветка.
7. Подключить модуль в Chrome и Firefox, добавить пункт F2 и скрытие при скриншоте.

12. Выводить каждое найденное совпадение отдельной строкой с фактическими данными должника
