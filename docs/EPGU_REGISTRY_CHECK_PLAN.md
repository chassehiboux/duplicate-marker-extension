# План: проверка формирования реестров ЕПГУ

1. Добавить локальную модель результата проверки, нормализацию взыскателей и правила
   агрегирования статусов.
2. Передавать в background список всех департаментов активной базы и ссылку возврата в
   исходный департамент.
3. В background открыть неактивную вкладку, последовательно переключать департаменты и
   читать `/ovzid/fsspreestr/data` за текущий день со всех страниц.
4. Гарантированно восстановить исходный департамент, закрыть служебную вкладку и вернуть
   фокус исходной вкладке.
5. Сохранять только полностью успешный дневной результат в локальном кэше без Supabase.
6. Добавить кнопку запуска, прогресс, второй статус, количество реестров и раскрывающуюся
   таблицу в существующую сводку ЕПГУ.
7. После успешной проверки перезагружать исходную страницу и автоматически открывать
   сводку с сохранёнными данными.
8. Проверить синтаксис, агрегацию статусов, удаление устаревшего кэша, Chrome/Firefox и
   актуальность deploy-скриптов.
