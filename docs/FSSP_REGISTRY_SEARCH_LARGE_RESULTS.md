# Большие результаты поиска ИД

Исправление зависания после проверки 1315 реестров и получения 21469 совпадений.
Причина в коде: после каждого пополнения результатов все строки группы создавались
заново, включая свёрнутые группы. Количество ячеек в документе росло без ограничения.

Теперь свёрнутые группы содержат только заголовок; открытые показывают по 100 строк
с кнопками «Назад» и «Далее», общим количеством страниц и сквозной нумерацией.
Все совпадения остаются доступными для просмотра и полной выгрузки в Excel.
При закрытии группы её строки удаляются из документа.

Область: отображение результатов существующего content script, элементы управления
внутри уже скрываемого при скриншоте окна. Новых пунктов F2 и самостоятельных
элементов расширения нет. StageTimer, постоянные ключи, Supabase, bridges,
permissions и состав сборок не меняются. Firefox использует тот же модуль;
deploy.py копирует каталог, deploy-firefox.py уже включает файл модуля,
deploy_VZID.py не включает поиск ИД. Изменения сборщиков не требуются.

Проверка: регрессия на 21469 совпадениях, границы страниц и полный результат,
синтаксис модуля и существующие тесты поиска.
