# Спецификация: выбор даты в сводке ЕПГУ

## Пользовательский результат

В окне «Сводка ЕПГУ» появляется компактный переключатель даты со стрелками. При каждом
обычном открытии выбрана текущая дата в формате `Пт 14.08.2026`.

Левой стрелкой можно последовательно перейти к любой дате вплоть до семи календарных
дней назад включительно. Правой стрелкой можно вернуться к текущей дате. На границах
доступного диапазона соответствующая стрелка заблокирована.

Список взыскателей, количество запросов, лучший статус и сообщение относятся только к
выбранной дате. При переключении базы выбранная дата сохраняется для автоматически
открытой сводки новой базы.

## Получение строк

Расширение не меняет количество строк и текущую страницу видимого грида. Оно получает
данные через штатный JSON-адрес `/ovzid/epgurequests/data` отдельными страницами по 300
строк, отсортированными по дате запроса от новых к старым.

Загрузка продолжается только до достижения нижней границы недельного диапазона. В окно
передаются и хранятся в памяти только строки от текущей даты до даты семь дней назад.
Серверная фильтрация по дате не используется: текущий endpoint её не применяет стабильно.
Размер 300 выбран как общий устойчивый предел для всех трёх баз; более крупные порции на
отдельных базах возвращают серверную ошибку.

Пока данные загружаются, окно показывает состояние загрузки и блокирует действия,
зависящие от сводки. Ошибка не маскируется данными одной видимой страницы грида:
пользователь получает понятное сообщение и может повторить загрузку повторным открытием
окна.

## Действия для выбранной даты

- «Проверить формирование реестров» доступна для любой выбранной даты и проверяет реестры
  именно за неё.
- Сохранённый результат проверки реестров выбирается по базе и выбранной дате.
- «Отправить запросы по неуспешным» доступна только для текущей даты. Для прошлой даты
  кнопка заблокирована, а подсказка объясняет ограничение.
- Проведение отдельного найденного реестра использует дату открытой сводки и обновляет кэш
  этой же даты.

## Локальное состояние

Загруженные строки недельного диапазона хранятся только в памяти вкладки и повторно
используются при переключении стрелками. Постоянный пользовательский ключ не создаётся.

Существующий локальный кэш проверки реестров расширяется до нескольких дат недельного
диапазона. Это служебный восстанавливаемый кэш, поэтому он не синхронизируется с
Supabase. Записи старше доступного недельного диапазона удаляются.

## Совместимость интерфейса

Переключатель находится внутри существующего окна ЕПГУ, поэтому скрывается вместе с ним
при создании скриншота и через пункт F2 «Сводка и повторы ЕПГУ». Активная логика остаётся
только в основном расширении; обособленный StageTimer получает общие стили без логики
ЕПГУ.
