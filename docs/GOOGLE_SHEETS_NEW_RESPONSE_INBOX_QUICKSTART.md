# Google Sheets New Response Inbox Quickstart

1. Обновить код `ProblemPickerBridge.gs` в Apps Script и заново развернуть Web app.
2. Обновить расширение обычным способом проекта.
3. Открыть целевую Google-таблицу и запустить общий сценарий через `F2` → `Старт`.
4. Закрытие модалки или вкладки не удаляет непрочитанные ответы.
5. Для продолжения открыть `F2` и нажать `Непрочитанные (N)`.
6. Нажимать `Прочитано и дальше`; каждая подтверждённая карточка удаляется сразу.
