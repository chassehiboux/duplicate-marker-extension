# План: выбор даты в сводке ЕПГУ

1. Добавить состояние выбранной даты и ограничить его диапазоном от текущей даты до семи
   дней назад включительно.
2. Получать строки штатного endpoint постранично по 300 записей, останавливаясь после
   достижения нижней границы диапазона, не меняя видимый грид.
3. Группировать загруженные строки по дате и строить существующую сводку из выбранного
   дневного набора.
4. Добавить стрелки, формат даты с сокращённым днём недели, загрузку и сообщения об
   ошибках.
5. Сохранять выбранную дату при переключении базы и восстанавливать её при автоматическом
   открытии сводки.
6. Привязать проверку, отображение, проведение и локальный кэш реестров к выбранной дате.
7. Отключить повторную отправку по неуспешным для прошлых дат, сохранив прежнее поведение
   для текущей даты.
8. Обновить общие стили, проверить основную и Firefox-сборки, deploy-состав и сценарии
   недельных границ.
9. До фоновой загрузки построить текущую сводку из уже видимых строк грида и сразу открыть
   предыдущую дату, только если она целиком присутствует на первой странице.
10. Блокировать переход к неполной дате и показывать на соответствующей стрелке
    анимированный индикатор до завершения фоновой загрузки.
