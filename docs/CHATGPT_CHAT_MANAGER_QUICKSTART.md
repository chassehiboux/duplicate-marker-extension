# Быстрый старт: управление чатами ChatGPT

1. Перезагрузить расширение на странице `chrome://extensions`.
2. Обновить открытую вкладку `https://chatgpt.com/`.
3. Навести указатель на обычный чат: справа появятся иконки архива и корзины. После корзины нажать зелёную галочку; уход указателя отменяет удаление.
4. Нажать кнопку со списком рядом с закрытием боковой панели для массового управления.
5. Раскрыть нужный проект. Все страницы его чатов загрузятся из боковой панели. Ниже расположен блок «Вне проектов»: его история подгружается автоматически. Знак «+» у счётчика означает незавершённую загрузку; при ошибке нажать «Продолжить загрузку».
6. Отметить отдельные чаты или нажать «Выбрать все» внутри нужного блока. Выбор других блоков не меняется; при поиске выбираются только совпадения в текущем блоке.
7. Нажать «Архивировать» или «Удалить». Для удаления повторно нажать подтверждение.
8. При необходимости нажать F2 и включить или скрыть блок «Управление чатами ChatGPT».
