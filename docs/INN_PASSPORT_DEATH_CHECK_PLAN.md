# План реализации перекрёстной проверки

## 1. Модель данных и оценка доказательств

- Описать исходный EDoc, человека, паспортный вариант, результат внешнего запроса и итог по каждой категории.
- Отделить отрицательные ответы сервисов от ошибок и капчи.
- Реализовать детерминированные правила выводов из спецификации.

## 2. Получение данных Пирамиды

- Загружать полную карточку EDoc напрямую в контексте текущего сайта.
- Реализовать поиск связанных долгов и EDoc по алгоритму PyramidReports.
- Поддержать пагинацию, точное сопоставление ФИО, даты рождения, лицевого счёта и адреса.
- Кэшировать карточки, запросы slowsearch и globalsearchsub в рамках одного запуска.

## 3. Внешние сервисы

- Вынести прямые запросы ФНС и Нотариата в background/service worker.
- Создать последовательный планировщик поиска ИНН с интервалом 11 секунд.
- Реализовать двухступенчатый запрос с датой выдачи и без неё.
- Реализовать бесконечное восстановление после капчи с уведомлением и паузой 30 секунд.
- Добавить ограниченную параллельность, повторы и увеличивающуюся задержку для остальных запросов.

## 4. Новый интерфейс

- Добавить действие в меню StageJump.
- Создать с нуля адаптивное модальное окно в утилитарном стиле «контрольного журнала»: карточки EDoc, ясная цветовая семантика, видимые основания выводов и раскрываемые ответы источников.
- Обновлять статус конкретного EDoc после каждого ответа Пирамиды, ФНС и Нотариата; добавить подробные подсказки при наведении, прогресс, уведомление о капче, отмену и повтор технических ошибок.
- Обеспечить скрытие интерфейса расширения при скриншотах и настройку видимости через F2.

## 5. Экспорт

- Формировать `.xlsx` без внешних зависимостей на основе уже существующего ZIP/XML-механизма проекта.
- Автоматически скачивать файл после завершения.
- Реализовать копирование итоговой таблицы в TSV и повторное скачивание.

## 6. Интеграция и удаление старой логики

- Полностью заменить старые скрытые вкладки и DOM-автоматизацию прямыми запросами.
- Формировать Excel только по явному нажатию пользователя, без автоматического скачивания.
- Синхронизировать основной background, manifest и Firefox/deploy-сборки.
- Не оставлять старые кнопки и старое окно проверки.

## 7. Проверка

- Проверить одиночный запуск без выделения.
- Проверить несколько выделенных загруженных строк.
- Проверить живой пример `18365109` и умерший пример `18366278`.
- Проверить отсутствие результата, другой ИНН, разные даты смерти, капчу, сетевую ошибку, отмену и Excel.
