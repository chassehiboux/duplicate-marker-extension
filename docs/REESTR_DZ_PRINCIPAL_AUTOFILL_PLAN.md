# План: заполнение сведений об отправке принципалу

1. Добавить модель запуска, последовательную очередь и состояния «работает», «пауза»,
   «требуется проверка», «завершено».
2. Перед сбором предлагать период по `RequestDate` с маской `dd.mm.yyyy-dd.mm.yyyy`, затем
   получать одним штатным запросом все строки текущего отфильтрованного грида и оставлять
   только записи без даты и номера исходящего, попавшие в период. Пустой период не ограничивает выборку.
3. Переключать видимую страницу грида по позиции текущей записи и подсвечивать строку.
4. Через background загружать карточку поручения и карточку исходящего WSS Docs с текущей
   авторизацией пользователя.
5. Разбирать единственную ссылку исходящего и верхнюю подпись `номер (дата)`; при нескольких
   ссылках включать обязательную ручную паузу.
6. После устойчивой загрузки грида выбирать и подтверждать строку через штатный jqGrid, открывать форму
   `/ovzid/ReestrDz/Send`, мгновенно вставлять дату и номер, нажимать штатную кнопку сохранения, ждать
   окончания перезагрузки грида и явно показывать подтверждение после повторной проверки значений.
7. Добавить утилитарный оверлей с прогрессом, текущей строкой, страницей, этапом, кнопками
   «Пауза»/«Старт» и крестиком с возможностью вернуть оверлей без сброса запуска.
8. Добавить итоговую статистику, автоматическое скачивание Excel и повторное скачивание
   кнопкой `📊`; включить в имя дату, название департамента и `depid`. Оформить лист
   компактно: шрифт 9 пт, светлый заголовок, закреплённая верхняя строка и узкие столбцы.
   Не загружать суммы состава отдельным JSON: проверка реестра № 3002 показала 22,9 секунды
   на 270 строк и отсутствие готовых итоговых значений в ответе.
9. После каждой строки сохранять дневной снимок по `depid` в `chrome.storage.local`, восстанавливать
   незавершённую очередь на паузе и исключать из новых запусков уже обработанные сегодня строки.
10. Включить функцию в F2, конфигурацию видимости и режим скрытия при скриншоте.
11. Проверить синтаксис, основной/Firefox deploy-состав, живой цикл и создать отдельный
    коммит без нерелевантных пользовательских изменений.
