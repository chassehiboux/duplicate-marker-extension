# Google Sheets New Response Inbox Plan

1. Добавить скрытый системный лист и стабильный формат записи непрочитанного ответа.
2. Объединить сохранение INFO, журналирование и сброс зелёной отметки в восстанавливаемую bridge-операцию.
3. Добавить bridge-действия чтения очереди, чтения счётчика и удаления прочитанной записи.
4. Передавать в bridge снимок карточки и возвращать постоянный идентификатор записи.
5. Перевести кнопку меню и модалку на постоянную очередь.
6. Удалять карточку только по нажатию единой кнопки `Прочитано и дальше`.
7. Обновить документацию и выполнить точечные проверки расширения и Apps Script.
