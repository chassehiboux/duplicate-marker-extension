# Проверка

1. Откройте `/call-center/reestrs/view?section=debt_claim` и найдите в нижней панели кнопку
   «Найти в реестрах».
2. Откройте окно и проверьте поля: ЛС, телефон, адрес, ФИО абонента, номер ИД и тип
   взыскания.
3. Введите часть известного значения и запустите поиск.
4. Убедитесь, что результаты появляются отдельными строками ещё до завершения поиска.
5. Проверьте поиск по нескольким заполненным полям одной строки.
6. Нажмите «Стоп», убедитесь в прекращении новых запросов, затем нажмите «Продолжить».
7. Откройте номер реестра из результата и проверьте прокрутку и зелёную подсветку строки.
8. Проверьте пустой результат, несколько строк критериев и независимую прокрутку таблицы.
9. Проверьте скрытие окна через F2 и во время создания скриншота.
