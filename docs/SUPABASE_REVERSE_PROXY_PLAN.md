# План reverse proxy для Supabase

1. Проверить прямую доступность Supabase с локального компьютера и VPS.
2. Добавить на VPS изолированный Nginx-маршрут `sb.jassco.ru` и выпустить TLS-сертификат.
3. Проверить конфигурацию Nginx и выполнить безопасную перезагрузку без остановки других сервисов.
4. Подключить расширение к прокси как к основному адресу, сохранив прямой Supabase как автоматический резерв.
5. Проверить REST и WebSocket через публичный адрес прокси.
6. Выполнить точечные синтаксические и deploy-проверки для обеих браузерных сборок.
7. Если восстановленный маршрут выявит серверную ошибку очереди, исправить её через миграцию и подтвердить повторный push по API-логу.
