# Поиск ITIL в настольной 1С

## Спецификация

После однократной установки помощника для расширения Edge кнопка «Старт» в Google Sheets получает данные ITIL из открытой локальной 1С:ITIL. Это относится к заполнению текста, обновлению ответов и случаям, когда при обработке СУПП нужны сведения из ITIL. Очереди, обработка СУПП и правила записи Google Sheets сохраняются.

Перед запуском открыть Service Desk в локальной 1С. Помощник выводит окно 1С на передний план. Если Windows блокирует смену фокуса, помощник даёт 15 секунд на ручное переключение. Затем он вводит значащую часть номера в поиск, открывает строку только по полному совпадению и сверяет номер в карточке. После чтения он закрывает открытую им карточку. Действие «Открыть заявку» оставляет карточку открытой.

Пока помощник не зарегистрирован для расширения, используется прежний веб-поиск. Ошибка зарегистрированного помощника видна в обычном статусе обработки. Настройка действует на этом компьютере через установку помощника. Новых ключей хранения и синхронизации нет.

## План и задачи

1. Проверить на реальной локальной 1С поиск, открытие, сверку номера и чтение заполненного решения.
2. Добавить Windows-помощник с Native Messaging. Он получает номер и тип операции, выбирает одно локальное окно ITIL и вызывает установленный Vercel agent-desktop. Только поиск и чтение, без записи в 1С.
3. Подключить к общему сборщику ITIL и действию открытия. Сохранить действующую обработку и таймауты веб-версии.
4. Проверить протокол, повторный поиск, несовпадение номера и отсутствие помощника. Проверить состав сборок основного расширения и StageTimer.
