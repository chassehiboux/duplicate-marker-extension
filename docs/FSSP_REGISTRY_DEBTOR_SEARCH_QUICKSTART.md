# Быстрый старт: поиск должников в реестрах ФССП

1. Откройте страницу «Реестры из ФССП» и при необходимости задайте фильтры списка.
2. Нажмите «Найти ИД в реестрах» после кнопки «Единый реестр ФССП».
3. Введите один или несколько признаков должника. Для пустого значения введите `null`.
4. Для следующего должника используйте автоматически появившуюся пустую строку.
5. Нажмите «Поиск» и дождитесь завершения прогресса.
6. Нажмите найденный ID реестра: он откроется в новой вкладке на подсвеченной строке должника.

Закрытие окна во время поиска отменяет проверку. Пустые строки и пустые поля не учитываются.

7. Во время поиска нажмите «Стоп» и убедитесь, что новые проверки и страницы перестали
   запускаться, а найденные результаты сохранились.
8. Нажмите «Продолжить» и убедитесь, что поиск возобновился с того же места.
9. По прогрессу убедитесь, что следующая страница списка начинается только после полной
   проверки предыдущей.
