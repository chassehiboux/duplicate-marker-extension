# Быстрый старт: поиск должников в реестрах ФССП

1. Откройте страницу «Реестры из ФССП» и при необходимости задайте фильтры списка.
2. Нажмите «Найти ИД в реестрах» после кнопки «Единый реестр ФССП».
3. Введите один или несколько признаков должника. Для пустого значения введите `null`.
   В поле «Статус» можно ввести весь статус записи внутри реестра или часть текста,
   самостоятельно либо вместе с остальными полями. Регистр букв не учитывается.
4. Для следующего должника используйте автоматически появившуюся пустую строку.
   Для массового ввода скопируйте один столбец Excel, щёлкните нужное поле (например,
   «ФИО») и нажмите Ctrl+V. Каждая непустая строка вставится отдельно сверху вниз,
   начиная с выбранной строки. Значения выбранного столбца заменятся, другие поля
   сохранятся. Для добавления к списку выбирайте последнюю пустую строку.
5. Нажмите «Поиск» и дождитесь завершения прогресса.
6. Нажмите найденный ID реестра: он откроется в новой вкладке на подсвеченной строке должника.
   Наведите указатель на ID, чтобы увидеть тип реестра во всплывающей подсказке.

Закрытие окна во время поиска отменяет проверку. Пустые строки и пустые поля не учитываются.

7. Во время поиска нажмите «Стоп» и убедитесь, что новые проверки и страницы перестали
   запускаться, а найденные результаты сохранились.
8. Нажмите «Продолжить» и убедитесь, что поиск возобновился с того же места.
9. По прогрессу убедитесь, что следующая страница списка начинается только после полной
   проверки предыдущей.
10. После нажатия «Поиск» под кнопками сразу появится отдельный свёрнутый блок для
    каждой заполненной строки, в порядке ввода. Заголовок показывает условия и «Найдено: 0».
11. Раскройте нужный блок: внутри будут все найденные для него записи по убыванию ID
    реестра. Ссылка открытия содержит ID и тип реестра. Счётчик обновляется в ходе поиска;
    раскрытые блоки остаются открытыми. Блоки без совпадений также остаются в списке.
    Для копирования значения щёлкните правой кнопкой мыши нужную ячейку результата.
    Ячейка открытия копируется как ID вместе с типом реестра.
12. При большом числе результатов проверьте независимую прокрутку нижней таблицы на полной
    высоте окна.

## Выгрузка в Excel

После запуска поиска нажмите «Выгрузить в Excel»: файл содержит результаты,
полученные к моменту нажатия. Для полного результата дождитесь завершения поиска.
Файл содержит обычную таблицу. Первый столбец «Параметры поиска» повторяет условия
поиска для каждой найденной записи. Используйте фильтр в заголовке этого столбца,
чтобы оставить записи с нужными условиями. Строки без совпадений выгружаются с условиями
и пустыми полями реестра. Группировка в окне поиска сохраняется.
В Excel попадают все поля найденной записи из реестра, включая отсутствующие
в окне поиска. Дополнительные поля отображаются под исходными названиями.
