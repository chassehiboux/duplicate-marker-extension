# Настройка локального поиска ITIL в Edge

1. Убедитесь, что локальная 1С:ITIL запущена, вход выполнен и в ней открыт Service Desk. Установите CLI Vercel командой `npm install -g agent-desktop`, если он ещё не установлен.
2. Если Edge уже загружает расширение из этого каталога, переключите каталог на ветку ITIL и нажмите «Обновить» в `edge://extensions`. При первой загрузке выберите «Загрузить распакованное расширение» и укажите каталог расширения. Скопируйте его ID в `edge://extensions`.
3. В PowerShell из каталога рабочей копии выполните команду, подставив ID расширения:

   ```powershell
   .\GoogleSheets\itil-desktop\install-edge.ps1 -ExtensionId 'ID_РАСШИРЕНИЯ'
   ```

   При установке из архива Vercel дополнительно передайте путь к нативному `.exe` через `-AgentDesktopPath`. Помощник устанавливается для текущего пользователя Windows. Если ID меняется, повторите установку с новым ID.

4. Для быстрой проверки нажмите «Открыть заявку» для номера ITIL в карточке расширения и сверьте номер в открывшейся 1С. Для обработки очереди выберите Service Desk и нажмите в Google Sheets F2 → «Поиск новых заявок, классификация, новые ответы» → «Старт». На время поиска дайте 1С работать на переднем плане. Если Windows оставила Edge поверх 1С, в течение 15 секунд переключитесь на Service Desk и вернитесь в Edge после поиска.
5. Проверьте текст, решение и дополнительные сведения в результате. Если карточку открыли вручную или кнопкой «Открыть заявку», перед следующим поиском выберите Service Desk.

После обновления расширения перезагрузите открытую вкладку Google Sheets, чтобы F2 запустил новый код.

Чтобы вернуть веб-поиск, удалите только регистрацию помощника:

```powershell
Remove-Item -LiteralPath 'HKCU:\Software\Microsoft\Edge\NativeMessagingHosts\ru.duplicate_marker.itil_desktop'
```

Справка по установке связи между Edge и приложением Windows доступна в [документации Microsoft](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/native-messaging).
