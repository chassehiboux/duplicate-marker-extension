# План реализации

1. Изучить структуру списка и содержимого реестров в авторизованной вкладке Chrome.
2. Добавить самостоятельный модуль поиска и кнопку в нижнюю панель списка реестров.
3. Создать полноразмерное окно с шестью полями, паузой и отдельной таблицей результатов.
4. Использовать серверные jqGrid-фильтры для состояний `queue`, `work` и `archive`.
5. Добавлять найденные задачи построчно и исключать дубликаты по ID задачи.
6. Реализовать переход к реестру, поиск строки по ID, прокрутку и подсветку.
7. Подключить модуль к основной и Firefox-сборке, F2 и режиму скриншота.
8. Выполнить точечные проверки и создать отдельный коммит.
