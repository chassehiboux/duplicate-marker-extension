# Проверка Supabase reverse proxy

1. Перезагрузить расширение в браузере.
2. Открыть popup и раскрыть блок Supabase.
3. Нажать «Проверить синхронизацию».
4. Убедиться, что тест завершился успешно, Realtime подключён, а очередь изменений стала пустой.
5. Изменить одну синхронизируемую настройку и убедиться, что время последнего push обновилось.
6. Во втором браузере нажать «Синхронизировать сейчас» и проверить получение изменения.

Если VPS недоступен, расширение автоматически пробует прямой адрес Supabase; ручное переключение не требуется.
